# Closing Tool

Single-File React Web-App zur Kostenrechnung und Leistungsnachweis-Generierung für Projekt-Bundles: Zeiterfassungs-Excel importieren, Rollen und Rate Cards zuordnen, Budgets verfolgen und Leistungsnachweise sowie Monats-/Budgetberichte als PDF exportieren.

Der eigentliche Code liegt in [`app/`](./app) — siehe dort für Setup, Entwicklung und Build.

```bash
cd app
npm install
npm run dev
```

`npm run build` erzeugt eine einzelne, portable `dist/*.html`-Datei, die sich ohne Server per Doppelklick öffnen lässt.
